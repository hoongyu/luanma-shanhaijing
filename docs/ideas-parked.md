## 1 · 星图引擎

把任意「二维 + 量级」的数据渲染成中国古星图（苏州石刻天文图、敦煌星图那一路）。

- **核心洞察**：星图是天生的精确散点图——位置是真的，星等映射量级，星官把散点分组并命名。它的美来自精确，不是来自渲染。这正好避开第一版手卷的失败（读不出精确值）。
- **视觉**：深色底 + 金/朱点 + 极细连线。天然同时满足极简与华丽。
- **复用性最高**：它是一个渲染引擎，可以吃很多不同题材的数据，不绑死在一个主题上。
- **待验证**：中国星官体系（三垣二十八宿）有没有可用的机读数据集。这是可行性的前提。

## 3 · 汉字三千年

输入任何一个汉字 → 看它从甲骨文 → 金文 → 篆 → 隶 → 楷的演变；同时展开构件树（部首 + 声符），以及共享声符的字组成的网络。

- **传播力最强**：每个人都有「自己的字」（名字里的字、喜欢的字）。输入即得、结果独一无二 → 天然的分享单元。
- **最适合 iOS**：一个字一张图，正好是手机屏。
- **视觉素材现成**：字形本身就是最好的图形，不需要发明装饰。演变过程天然是「流畅切换动画」。

### ✅ 2026-08-12 已完成可行性核查 —— 结论：**要砍掉一半才能做**

**甲骨 → 金文 两段 = 事实不可行**

| 阻碍 | 事实 |
|---|---|
| Unicode | **甲骨文至今未编码**，Plane 3 上仅暂定预留（2003 年提案至今未完成）；**金文连详细提案都没有** |
| 最大开源数据集 | HUST-OBC（华科 VLRLab，Nature *Scientific Data* 2024）14 万张图 —— **CC BY-NC 4.0 禁商用，且全是位图非矢量** |
| 学术权威源 | 小學堂（22 万+ 字形）官方声明授权「仍在研議」＝连非商用都没授权；hanziyuan.net 仅 All rights reserved；殷契文渊「免费开放」指访问非再授权 |
| **真正的天花板** | **全球已释读甲骨字头只有约 1,100–1,600 个。** 常用 3000 字里能凑齐五段的乐观估计 **不超过 800–1,000 字**。原因是大量常用字是后起形声字，**商代根本不存在** —— 再多经费再等十年都不会变 |

**篆 → 隶 → 楷 三段 = 可行，今天就能开工**

| 用途 | 字体 | 授权 | 关键性质 |
|---|---|---|---|
| 小篆 | **崇羲篆體** | CC BY-ND 3.0 TW（可商用） | 11,599 字。**字形直接挂标准 CJK 楷书码位 → 输入楷书换字体即出篆书，不必等 Unicode 18.0**（小篆 11,328 字将于 2026-09-16 随 18.0 发布） |
| 隶书 | **教育部標準隸書 Ver 3.00** | CC BY-ND 3.0 TW | 仅 4,808 繁体常用字，须署名「中華民國教育部」 |
| 楷书 | **全字庫正楷體** | 政府開放授權 或 OFL（二择一） | 唯一可任意子集化的 |
| 笔顺 | **Make Me a Hanzi** | Arphic Public License **1999 版**可商用（2010 版限非营利，看包内年份） | 9,000+ 字矢量笔顺 |

**三条必须写进立项文档的约束**

1. **崇羲篆體与教育部隸書都是 ND（禁止改作）→ 不可子集化**，只能整包投递 + 必须署名。这直接影响架构，先下载称重再定
2. 两款都是繁体导向、4,808–11,599 字级，**生僻字掉字率必须先用真实字表实测**，没测之前任何推荐都是纸上谈兵
3. ⭐ **「哪些字老到有甲骨文」本身就是内容。把覆盖率上限当特性讲，不要当缺陷补** —— 这是整份核查里最有价值的产品判断

**唯一可能翻盘的动作**：给 Richard Sears（hanziyuan.net，96,000+ 古字形含甲骨金文，以开放态度著称、长居中国）写一封信谈授权。**成本一封邮件，对应甲骨金文段从「事实不可行」翻盘的可能性。**

→ **立项判据**：按「输入任意汉字看完整五段」= 不要做。按「三段全覆盖 + 精选数百明星字补甲骨金文」= 可做。
